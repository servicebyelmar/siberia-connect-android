# Siberia Connect Тест — новый интерфейс (тестовая сборка 1.3.2-ice2, сборка 793)

Название на телефоне: **Siberia Connect Тест** (пакет `com.siberiaconnect.vpn.test`). Ставится **рядом** с обычным приложением, данные раздельные.
Версия и коммит сборки — внизу вкладки «Настройки» (сообщайте их вместе с замечанием).

## Установка
1. Скачать APK `SiberiaConnectTest_*_universal.apk` (артефакт CI `test-ice-universal-apk`, внутри zip).
2. Разрешить установку из источника (браузер/«Файлы»), установить.
3. Обычное приложение не удалять и не останавливать, но **на время теста выключите в нём VPN** — одновременно работает один VPN.

## Ключ / аккаунт
Отдельный тестовый ключ **не создавался**. Варианты:
- первый запуск сам заведёт аккаунт с пробным днём (если на устройстве его не было — защита от повторных триалов может отказать);
- либо «Настройки → Подписка → Ввести ключ или код» и ввести ключ тестера.
Внимание: тестовое приложение — отдельное устройство для сервера, может занять слот лимита устройств. После теста: «Настройки → Выйти из аккаунта».
Ссылки `siberiaconnect://` открывают выбор приложения (оба пакета их понимают) — выбирайте «Тест».

## Чек-лист (шаг → ожидаемо)
| # | Шаг | Ожидаемый результат |
|---|---|---|
| 1 | Открыть «Siberia Connect Тест» | Графитовый экран: сверху статус «Отключено», в центре крупная тёмная круглая кнопка питания на серебристой шерсти (неподвижной), под ней подпись «Подключиться», ниже строка выбора сервера, внизу вкладки «Главная · Серверы · Настройки» |
| 2 | Свернуть, открыть снова; потом смахнуть из «недавних» и открыть | Тот же новый интерфейс (не старый кабинет) |
| 3 | Нажать на кнопку | Кнопка слегка утапливается, по шерсти проходит волна инея, статус «Подключение…», подпись «Отменить». После подтверждения VPN: «Подключено», кнопка ледяно-голубая со тёмным знаком, за ней проявляется кристалл и падает мелкий снег, идёт «Время сеанса», подпись «Отключиться» |
| 4 | Быстро нажать на кнопку дважды | Ровно одно подключение (не «подключилось и сразу отключилось») |
| 5 | Нажать на кнопку при «Подключено» | «Отключено», снег стихает, возвращается шерсть, подпись «Подключиться», таймер исчезает |
| 6 | Во время «Подключение…» нажать на кнопку ещё раз (подпись «Отменить») | Отмена, «Отключено», VPN не включается позже |
| 7 | Подключено → свернуть на минуту → вернуться | Статус и таймер соответствуют реальности (таймер не сбросился) |
| 8 | Подключено → выключить VPN из шторки Android / ключ-иконки → вернуться | Показано «Отключено» |
| 9 | Включить режим полёта → нажать на волка | «Ошибка подключения», графитовая кнопка с подписью «Повторить», причина текстом над кнопкой, снег остановлен. Выключить режим → «Повторить» → подключается |
| 10 | Нажать на строку сервера на главной | Открывается «Серверы» одним нажатием |
| 11 | «Серверы»: вверху видно, через какой узел идёт соединение | Блок «Подключено через …» / «Выбрано» |
| 12 | Нажать на страну с несколькими узлами | Раскрывается список узлов с задержкой; одиночный узел выбирается сразу |
| 13 | Выбрать другой узел при включённом VPN | Главная: «Переключаю узел…» → «Подключено» через новый узел |
| 14 | Выбрать «Автовыбор» | Помечен «ВКЛЮЧЁН»; при подключении выбирается быстрый узел |
| 15 | «Проверить» | Задержки обновляются (не более ~10 с) |
| 16 | Подписка с одним сервером (если есть такой ключ) | Экран «Ваш сервер» с одной карточкой и пояснением, без пустых мест |
| 17 | «Настройки»: открыть все пункты | Группы «Подключение / Маршрутизация / Подписка / Система и поддержка»; тарифы, бонусы, ключ, поддержка открывают старый кабинет с кнопкой «‹ В приложение»; «Назад» возвращает в приложение |
| 18 | «Приложения без VPN» | Открывается список со поиском, «Сохранить» применяет |
| 19 | Увеличить шрифт: Настройки Android → Дисплей → Размер шрифта (макс.) | Подписи кнопок и нижней навигации читаются целиком, слова не рвутся |
| 20 | Тёмная/светлая тема системы | Интерфейс остаётся графитовым |

## Что отправлять при замечании
Скриншот/видео, версия и коммит из «Настроек» (внизу), код обращения с экрана ошибки (если показан).

## Ограничения этой сборки
- обновление из приложения отключено (чтобы не подтянуть боевой APK);
- старый кабинет (тарифы, оплата, бонусы, поддержка) пока прежний — он открывается из «Настроек»;
- вход через ссылку из бота открывает старый кабинет для входа, потом «‹ В приложение».

## Обновление поверх предыдущей тестовой версии
Подпись и пакет те же, номер сборки выше (793 > 792): устанавливайте APK поверх — вход и настройки тестовой версии сохранятся. Если Android пишет «конфликт» — удалите тестовое приложение (обычное не трогайте) и поставьте заново.
